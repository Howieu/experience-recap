# experience-recap

产品经理岗位（AI 产品、策略产品、Agent 产品、数据产品）的面试经历复盘 skill。它把简历上的一段个人项目或实习逐题深挖成一张“经历卡片”：每节先给面试时能直接说的口头版，再给取舍、追问、bad case 和不完美之处；所有事实都要能追溯到代码、文档或本人确认；最后用各张卡片反推自我介绍和个人优势。

## 它按什么标准复盘

- **面试官只知道简历和你说的话。** 题目从简历的每一句话引出，口吻是“我注意到你有 X，你是怎么做到的？怎么确信……？”，不问真假，不以源码细节为前提。
- **讲 how、why 和取舍。** 机制要具体到脚本、规则和校验，不说“靠约定”；取舍选面试官真会问的那个。
- **每个数字带口径**：离线、线上、估算还是缺，样本多大，和什么比，谁判的。
- **主动准备不完美**：否决过的方案、没校准的门槛、没做的对比。
- **bad case 用四段式**：分类和成因 → 每类一例 → 解法 → 结果影响。
- **业务价值讲传导链和归因**：落到收入公式，用随机留出证明是产品带来的。

## 会考察哪些方面

需求与根因、关键概念的产品立场、为什么用 AI / Agent、评估与指标（离线、线上反馈、采纳、价值四层）、防错、能力边界、简历上每个特性的实现机制、复杂度取舍、降级策略、核心策略与门槛回查、业务价值、bad case。实习经历按“参与的三四块”组织。

## 安装

```bash
git clone https://github.com/Howieu/experience-recap.git ~/.claude/skills/experience-recap
```

装好后，在 Claude Code 里说“帮我复盘一下这段实习经历”“grill 我这个项目”“面试官会怎么问我这个项目”之类的话就会触发。

## 文件

| 文件 | 内容 |
| --- | --- |
| `SKILL.md` | 主流程：出题原则、开始前要做的事、逐题深挖的步骤、卡片写法标准、收尾 |
| `references/question-tree.md` | 13 个深挖模块：面试官底层在问什么、推荐答案要包含什么、去哪里查证据 |
| `references/golden-cases.md` | 脱敏的好答案与坏答案对照：出题、“你是怎么做到的”、边界题、复杂度取舍、bad case、业务价值 |
| `references/lessons.md` | 容易再犯的错误，按事实、读题、写法、节奏分类 |
| `references/card-template.md` | 卡片文件的结构和常用表格 |
